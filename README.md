## TL;DR

5 шкал прогресса (XP/lifetime, стрик, попытки, рекорд, lifetime тренировок) + 6-я шкала (удаление по неактивности). XP считается по формуле на базе MET (отраслевой стандарт WHO/ACSM). Уровни — экспонента ×2 от 420 XP. Стрики — стандартные magic numbers (7, 14, 30, 60, 100, 180, 365). Стрик отделён от удаления: сгорание стрика ≠ удаление из чата. Это сознательный сдвиг от Burn-DNA Strategy v2.0 — снижает риск «первое сгорание = удаление приложения».

## 2. ШКАЛА 1 — XP

### 2.1 Принцип

| Параметр | Значение |
|---|---|
| Назначение | Прогресс по объёму и качеству тренировок · переход на уровни · ресурс для спасения от удаления |
| Старт | 0 XP |
| Сгорание | Только при спасении через XP — теряются **все** XP, уровень сбрасывается до L1 |
| Сброс при удалении из чата | Полный сброс до 0 |

### 2.2 Формула начисления

> **XP = (длительность × интенсивность × тип-коэффициент) / 5**, минимум 1 XP

Принцип основан на упрощённом MET-подходе (Metabolic Equivalent of Task) — отраслевом стандарте WHO/ACSM, лежащем в основе Apple Health, Google Fit Heart Points, Strava, Weight Watchers Activity Points.

**Параметры:**
- **Длительность** — целое число минут, от 1 до 480
- **Интенсивность** — шкала 1–5: 1 — Разминка, 2 — Комфортно, 3 — Рабочий темп, 4 — Тяжело, 5 — На пределе
- **Тип-коэффициент** — определяется типом активности (см. §2.3)

### 2.3 Типы активностей и коэффициенты

Соответствуют типам в дизайне Mini App (скрин 3):

| Тип в UI | Коэффициент | MET-аналог |
|---|---|---|
| Йога, Растяжка | 0.8 | низкий, ~2–3 |
| Ходьба | 0.8 | низкий, ~3 |
| Гребля | 1.0 | средний, ~4 |
| Силовая, Гиря, Танцы | 1.0 | средний, ~5 |
| Воркаут | 1.0 | средний, ~5 |
| Плавание | 1.2 | высокий, ~7 |
| Велосипед, Бег | 1.2 | высокий, ~8 |
| Кардио | 1.2 | высокий, ~7 |
| Кроссфит, HIIT | 1.5 | очень высокий, ~10+ |
| Другое | 1.0 | default |

### 2.4 Калибровка (примеры)

| Сценарий | Расчёт | XP |
|---|---|---|
| 1 минута отжиманий, инт.1, силовая | 1 × 1 × 1.0 / 5 = 0.2 | **1** (минимум) |
| 5 мин йога, инт.1 | 5 × 1 × 0.8 / 5 = 0.8 | **1** (минимум) |
| 30 мин йога, инт.3 | 30 × 3 × 0.8 / 5 = 14.4 | **14** |
| 60 мин силовая, инт.3 (как на скрине 2) | 60 × 3 × 1.0 / 5 = 36 | **36** |
| 45 мин силовая, инт.4 | 45 × 4 × 1.0 / 5 = 36 | **36** |
| 60 мин бег, инт.4 | 60 × 4 × 1.2 / 5 = 57.6 | **58** |
| 30 мин HIIT, инт.5 | 30 × 5 × 1.5 / 5 = 45 | **45** |
| 90 мин HIIT, инт.5 | 90 × 5 × 1.5 / 5 = 135 | **135** |

> **Расхождение в текущем дизайне** (скрин 2 показывает `+6 XP за силовую 60 мин инт.3` вместо корректного `+36 XP`) — **правится сразу до релиза**, дизайн синхронизируется с моделью.

### 2.5 Уровни (множитель ×2)

| Уровень | XP в уровне | XP накопит. | Название (placeholder) | Темп при 100 XP/нед |
|---|---|---|---|---|
| L1 → L2 | 420 | 420 | Новичок | ~4 недели |
| L2 → L3 | 840 | 1 260 | Любитель | ~3 месяца |
| L3 → L4 | 1 680 | 2 940 | Стабильный | ~7 месяцев |
| L4 → L5 | 3 360 | 6 300 | Машина | ~15 месяцев |
| L5 → L6 | 6 720 | 13 020 | Легенда | ~2.5 года |
| L6 → L7+ | 13 440 | 26 460 | TBD | endgame |

**Калибровка при среднем темпе:** 4 тренировки/нед × ~25 XP = ~100 XP/неделю → L1 за ~4 недели, L4 за ~10 месяцев. Соответствует амбициозному, но реалистичному PMF-горизонту.

> **Расхождение в текущем дизайне** (скрин 5 показывает `66 XP / 200` — порог 200 вместо 420) — **правится сразу до релиза**, порог в коде уровней синхронизируется с моделью.

| Параметр | Значение |
|---|---|

## 4. ШКАЛА 3 — ПОПЫТКИ ДЛЯ ПРОДЛЕНИЯ СТРИКА

| Параметр | Значение |
|---|---|
| Старт на L1 | 1 попытка |
| Прирост | +1 попытка за каждый новый уровень |
| Максимум | **7 попыток** |
| Конвертация | Нельзя (не обмениваются на XP, деньги или другие ресурсы) |
| Назначение | Защита Шкалы 2 (стрика). **Не защищают от удаления** |
| Применение | Двухслойное — см. §4.2 |
| Поведение при спасении через XP | Обнуляются (0 из 1, как у нового юзера на L1) |

### 4.1 Прирост попыток по уровням

| Уровень | Попытки на старте уровня (без трат) |
|---|---|
| L1 | 1 |
| L2 | 2 |
| L3 | 3 |
| L4 | 4 |
| L5 | 5 |
| L6 | 6 |
| L7+ | 7 (cap) |

### 4.2 Применение попыток — двойной механизм (Q-8)

Согласно решению Q-8, попытки применяются **обоими способами**:

| Способ | Описание | UI |
|---|---|---|
| (a) Видимая плашка в профиле | «Попытки: N/M» — пользователь видит свой буфер всегда | Скрин 5 — добавляется блок попыток |
| (b) Автопредложение в момент пропуска | Бот пишет: «У тебя пропуск, использовать попытку?» | Pop-up в Mini App + сообщение от Лео в боте |

Логика: пассивная видимость + активное предложение. Это снижает риск «юзер не знает, что у него есть попытка» и не требует ручной траты в скрытом меню.

> **Фича автопредложения попытки** прорабатывается отдельной сессией (UX flow, тексты, edge cases). В этом документе фиксируется только продуктовое решение Q-8 — оба механизма доступны.

## 6. ШКАЛА 6 — УДАЛЕНИЕ ПО НЕАКТИВНОСТИ

### 6.1 Триггер удаления

| День неактивности | Событие |
|---|---|
| 5 | Предупреждение от бота Лео |
| 6 | Предупреждение + варианты спасения (тренировка / 50 ₽ / траты XP) |
| 7 | Финальное предупреждение |
| 8 | Удаление из чата |

### 6.2 Способы избежать удаления (Q-4)

3 способа. Все три **в MVP**.

| Способ | Стоимость | Условие | UI |
|---|---|---|---|
| Любая тренировка | Бесплатно | Сбрасывает счётчик неактивности | Кнопка «+» в Mini App (скрин 1) |
| Платное продление | 50 ₽ → +7 дней | Telegram Stars / ЮKassa | Burn warning экран, кнопка «Купить продление» |
| Потратить все XP | XP → 0, уровень → L1, попытки → 0 (из 1) | **XP > 0 required** | Burn warning экран, кнопка «Спасение через жертву XP» с подтверждением |
| `#sick_leave` | Бесплатно (правила TBD) | Юзер на паузе, счётчик не идёт | Хэштег в чате стаи или кнопка «Больничный» |
