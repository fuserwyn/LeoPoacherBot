# Задача трекера #5

Задача #5.

добавь новую леопардовую тему

## Агент

1. Создам новую тему в `src/themes` на основе существующей леопардовой темы.  
2. Изменю цвета и градиенты, сохраняя паттерн.  
3. Обновлю `src/themes/index.ts`, добавив новую тему в экспорт.  

План:  
1. Скопировать `src/themes/fat-leopard.ts` в `src/themes/new-leopard.ts`  
2. Подобрать новую цветовую схему (например, сине-серую)  
3. Добавить экспорт в `src/themes/index.ts`:  
```ts
export * from './new-leopard';
```
