Сделано для задачи #54 — графики в разделе «Ачивки» по истории тренировок из БД.

**Бэкенд** (уже было + доработка):
- `GetTrainingCountsByDay` — агрегация по `session_date` из `training_sessions`

- `/api/miniapp/profile/load` отдаёт `workouts_by_day`

**Фронтенд** (уже было + доработка):

- `ProfileDayChart` — два графика в «Ачивках»: «Тренировки по дням» и «Стрик по дням»
- При изменении счётчика тренировок графики перечитываются из API
