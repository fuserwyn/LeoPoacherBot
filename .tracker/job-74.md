# Задача трекера #70

Задача #70.

При постановке задачи в трекере нужна опция добавления нескольких фото сразу  должен поддерживаться мульт выбор

## выполнение

Сделано для задачи #70:

**TaskImageEditor** — при постановке новой задачи включён мультивыбор (`multiple` на input). Если выбрано несколько файлов, они сразу добавляются как вложения (без редактора). Один файл по-прежнему открывается в редакторе с кропом и рисованием.

**TrackerScreen** — вместо одного фото теперь массив: превью всех выбранных картинок, удаление по одной, кнопка «Ещё фото» для добавления. При создании задачи все фото прикладываются к ней последовательно.

**TrackerScreen.css** — сетка превью для нескольких изображений.

Локальный коммит не создан: в окружении не настроен git user (config не трогал). Изменения в рабочей директории — трекер может закоммитить и запушить в `tracker/70-593`.
