# Задача трекера #59

Задача #59.

Сделать обращение в поддержку в поднимающейся шторе по аналогии с форматом открытия страницы ввода тренировки

## выполнение

Сделано: обращение в поддержку открывается в поднимающейся шторке, как форма ввода тренировки.

**SupportScreen.tsx** — вместо полноэкранного чата:
- затемнённый backdrop (тап закрывает);
- шторка с грабером и кнопкой ✕;
- свайп вниз для закрытия;
- проп `onClose` для родителя;
- убран `body--lock` (шторка — оверлей, не отдельная страница).

**SupportScreen.css** — стили шторки (`.sup`, `.sup-backdrop`) по образцу `.nwo`/`.admin`: зазор сверху, скругление, анимация; чат внутри шторки на flex, подъём над клавиатурой через `--app-keyboard-bottom`.

**App.tsx** — в `SupportScreen` передаётся `onClose={() => setSupportOpen(false)}`.

Локальный коммит не создан: в окружении не настроен git user.name/email (по правилам конфиг не трогаю). Изменения в рабочей копии на ветке `tracker/59-547`, трекер может закоммитить и запушить сам.
