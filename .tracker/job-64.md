# Задача трекера #4

Ревью задачи #4 на модели Cursor Composer.

Формулировка:
добавь новую леопардовую тему в розовых тонах

Что сдал агент:
Тест не прошёл. 

Не хватает:
1. Миграции для новой темы.
2. Проверок, что старая тема продолжает работать.
3. Тестов отрисовки розовой палитры.

Прочитай изменения в репозитории и реши, можно ли пускать на тест.
Если в репозитории нет коммита/ветки этой задачи, а есть только план — напиши «ревью не принято».
Если всё ок — коротко что проверил и напиши фразу «можно на тест».
Если есть блокеры — что починить и напиши «ревью не принято».

## Агент

Проверил репозиторий. Коммит с изменениями отсутствует, есть только план правок. 

Блокеры:
1. Не добавлена миграция для новой темы.
2. Нет проверок работы старой темы.
3. Отсутствуют тесты для розовой палитры.

Ревью не принято.
