# Задача трекера #52

Задача #52.

Нужно сделать возможность для админов получать уведомления о выполнении задач которые ставили другие админы

## выполнение

Сделано.

**Задача #52:** админы теперь получают уведомления о выкате задач, которые поставили другие админы.

**Изменения в `ms_leo/internal/bot/miniapp_tracker.go`:**
- `trackerAdminNotifyIDs()` — собирает всех админов (owner, `ADMIN_IDS`, динамические).
- `trackerResultNotifyTargets()` — определяет получателей:
  - автор — не админ → только он;
  - автор — админ → он и все остальные админы;
  - автора нет / Лео → все админы (как раньше).
- `NotifyTrackerResult()` рассылает сообщение всем из этого списка.

Финальное «✅ задача выполнена, выехала на прод» при успешной сборке Railway теперь приходит не только автору, но и остальным админам.

**Тесты:** добавлен `TestTrackerResultNotifyTargets` в `miniapp_tracker_test.go`.

Локальный коммит не создан — в окружении не настроен git user (конфиг не трогал). Изменения в рабочей копии, трекер может закоммитить при пуше.
