# Задача трекера #47

Задача #47.

в трекере может выполняться одновременно только одна задача, это нужно чтоб изолировать код и не приводило к конфликтам
если ставится задача, а другая уже выполняется, то ставящаяся задача идет в ожидание, пока не завершится выполнение предыдущей
то есть необходимо организовать очередь

## выполнение

Сделана очередь: в трекере одновременно выполняется только одна задача.

**ms_tracker**
- `ClaimDue` берёт не больше одной задачи и только если нет задачи со статусом `running`
- воркер запрашивает лимит `1` вместо `3`

**ms_leo (доска)**
- `ClaimDueTrackerTasks` берёт одну карточку из «Ожидает» только когда в конвейере (`doing` / `review` / `test` / `deploy`) никого нет
- `dispatchTrackerAgent` и `kickStuckTrackerAgents` не запускают агента, пока другая задача в конвейере
- добавлены тесты `tracker_queue_test.go`

Локальный коммит не создан — в окружении не настроен git user (конфиг не трогал). Изменения в staging area, трекер может закоммитить при пуше.
