# Задача трекера #69

Задача #69.

В поддержке при попытке ввести сообщение нужно чтоб последние сообщения были над клавиатурой, а сейчас она их перекрывает 

Исправь баг

## выполнение

Исправлен баг в `SupportScreen.tsx`.

**Проблема:** при открытии клавиатуры шторка поддержки поднималась через CSS (`--app-keyboard-bottom`), но лента сообщений не прокручивалась — последние сообщения оставались под полем ввода.

**Решение:** добавлена та же логика прокрутки, что уже работает в чате с Лео (`ChatScreen.tsx`):
- `ResizeObserver` — прокрутка при изменении высоты ленты (когда шторка сжимается из‑за клавиатуры)
- слушатели `visualViewport` — удержание низа ленты у поля ввода во время анимации клавиатуры
- `MutationObserver` на `app-keyboard-open` — корректная прокрутка после закрытия клавиатуры
- отслеживание жеста скролла, чтобы не мешать чтению истории

Коммит не создан: в окружении не настроен git user identity. Изменения в файле готовы, трекер может закоммитить сам.
