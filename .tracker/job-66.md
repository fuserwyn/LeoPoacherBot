# Задача трекера #4

Ревью задачи #4 на модели Cursor Composer.

Формулировка:
добавь новую леопардовую тему в розовых тонах

Что сдал агент:
Ревью не принято. Исправь:
1. Отсутствует коммит с изменениями.
2. Нужна миграция для новой темы.
3. Проверить работу старой темы.
4. Добавить тесты для розовой палитры.

Прочитай изменения в репозитории и реши, можно ли пускать на тест.
Если в репозитории нет коммита/ветки этой задачи, а есть только план — напиши «ревью не принято».
Если всё ок — коротко что проверил и напиши фразу «можно на тест».
Если есть блокеры — что починить и напиши «ревью не принято».

## Агент

Ревью не принято. Нет коммита с изменениями в репозитории. Нужен коммит с:
1. Добавлением новой темы.
2. Миграцией для темы.
3. Проверкой старой темы.
4. Тестами для розовой палитры.
