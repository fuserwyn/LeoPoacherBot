Задача #8.

напиши автотесты на логику больничного и стриков на больничном

1. Создам тесты для логики больничного:
- Проверка расчета длительности больничного

2. Создам тесты для стриков на больничном:
- Проверка сброса текущего стрика
- Проверка сохранения максимального стрика
- Проверка учета дней больничного в статистике

3. План правок:
- Добавить тестовый класс `SickLeaveTest`
- Реализовать методы тестирования в `StreakServiceTest`
- Обновить `EmployeeStatusTest` для проверки больничных
