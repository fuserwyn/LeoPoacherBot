# Задача трекера #54

Задача #54.

Для построения графиков в разделе ачивок нужно строить по датам тренировок смотреть историю из бд

## выполнение

Сделано:

**Бэкенд**
- `GetTrainingCountsByDay` в `training_sessions.go` — агрегация сессий по `session_date` из `training_sessions`.
- `GetMiniappWorkoutsByDayForAPI` в `miniapp_user_profile.go` — 90 дней по локальному TZ пользователя, merge pack + private row.
- В `/api/miniapp/profile/load` добавлено поле `workouts_by_day`.

**Фронтенд**
- `profileCharts.ts` — парсинг данных и восстановление стрика по правилам бэкенда.
- `ProfileDayChart` — горизонтально прокручиваемые столбчатые графики.
- В разделе «Ачивки» (при раскрытии) два графика за 90 дней:
  - **Тренировки по дням** — количество тренировок на дату
  - **Стрик по дням** — длина стрика на каждый день
- Графики перечитываются из API при изменении счётчика тренировок.
