### Fat Leopard — Telegram Mini App с AI-тренером
**Роль:** Tech Lead, Go Backend Developer

Спроектировал и разработал **с нуля полноценное приложение** для трекинга тренировок с AI-агентом и системой задач.

#### Архитектура и реализация
- **Go-бот** как основной backend: обработка команд, бизнес-логика, интеграция с Mini App
- **AI-агент на базе LLM (Deepseek)** с векторным хранилищем **Qdrant**
  - Генерация персонализированных тренировочных планов
  - Анализ прогресса пользователя
  - Ответы на вопросы о тренировках в реальном времени
- **Task Tracker / Система задач:**
  - Автоматическая генерация тренировочных задач AI-агентом
  - Трекинг выполнения упражнений
  - Система напоминаний и уведомлений
  - Прогресс-трекинг с визуализацией

#### Технические особенности
- **Go (Echo framework, Zap logging)** для REST API и Telegram Bot API
- Event-driven архитектура для асинхронной обработки
- **PostgreSQL** для хранения данных пользователей, тренировок и задач
- **Qdrant** векторное хранилище для AI-контекста
- Система геймификации: XP/MET по стандартам WHO/ACSM
- Социальная лента «стаи» с real-time обновлениями
- Интеграция платежей: Telegram Stars, ЮKassa
- **Мониторинг:** Prometheus метрики, Zap structured logging
- **Деплой:** Docker, Railway с автоматическим CI/CD
- TypeScript/Vite для Mini App фронтенда

#### Результаты
- Полностью работающий продукт с AI-агентом и task tracker'ом
- Автоматизация создания и управления тренировочными задачами
- Персонализированный опыт через LLM-интеграцию
- Production-ready архитектура с мониторингом и логированием

**Стек:** **Go (Echo, Zap)**, Python, TypeScript/Vite, PostgreSQL, Qdrant, Prometheus, Docker, Railway
