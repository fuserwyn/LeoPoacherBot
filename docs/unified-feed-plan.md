# Единая лента (чат + тренировки) — план

## Цель (из ТЗ)
- Таб-бар остаётся полностью: **Стая · Лео · + · Правила · Профиль**, но в область бара
  добавляется **поле ввода текста**. Поле ввода + кнопка «+» — единый компоуз-блок:
  - текст → публикует **сообщение** в ленту (пишется в `miniapp_pack_group_chat`, как сейчас чат);
  - «+» → открывает форму **тренировки** (пишется в `user_messages`, как сейчас).
- Внутри «Стая» больше нет подвкладок «Лента/Чат» — **один общий поток**.
- Фильтр потока: **Всё / Только тренировки / Только сообщения**.
- Сообщения в ленте: фото, комменты, реакции.
- **Единая сортировка и пагинация** по всему потоку.

## Данные (без переезда таблиц)
- Тренировки/системные карточки: `user_messages` (типы `training_done`, `pack_join`, `admin_post`…).
- Сообщения чата: `miniapp_pack_group_chat` (+ реакции `miniapp_pack_group_reactions`).
- Объединяем **на чтении** в эндпоинте `/api/miniapp/feed`.

## Технические решения
1. **Курсор пагинации — по `created_at`** (RFC3339), не по `id`.
   Запрос: `{ before_ts?, since_ts? }`. Ответ: как раньше `{ items, pinned }`.
2. **Дискриминатор источника**: у `PackFeedItem` добавляем поле `source` = `"feed" | "message"`.
   Тип сообщения-карточки: `type = "pack_message"`.
3. **Составной ключ на фронте**: `` `${source}:${id}` `` — id из разных таблиц могут совпасть.
   Все действия (реакции/редакт/удаление/комменты) роутятся по `source` в нужный эндпоинт.

## Фазы
### Фаза 1 — Бэкенд: объединённое чтение ленты  ← начинаем
- DB: новые запросы с курсором по времени для обеих таблиц
  (`ListPackActivityFeedPage`, `ListMiniappPackGroupChatPage` — before_ts/since_ts).
- bot: `PackFeedForViewer` мёржит оба источника (k-way по `created_at DESC`),
  маппит сообщение → `PackFeedItem{ source:"message", type:"pack_message", reactions, training_photo_url=photo }`.
- Обогащение: реакции сообщений (уже есть `enrichPackGroupChatReactions`), аватары авторов.
- handler: принимает `before_ts/since_ts` (старые `since_id/before_id` оставляем для совместимости на переходный период).

### Фаза 2 — Фронт: единый поток + фильтр
- `FeedScreen`: убрать подвкладки, оставить один список; фильтр Всё/Тренировки/Сообщения.
- Пагинация на `*_ts` курсорах; ключи/дедуп по `source:id`.
- Рендер `pack_message` карточкой (фото + реакции).

### Фаза 3 — Компоуз-блок в таб-баре
- В область `BottomNav` добавить поле ввода; поле + «+» — единый визуальный блок.
- Enter/кнопка отправки → POST `/api/miniapp/pack-group/messages` (как сейчас чат) →
  оптимистичная вставка в ленту + рефреш.

### Фаза 4 — Комменты к сообщениям
- Дать сообщениям тред как у тренировок. Тред-таблица сейчас привязана к `user_messages.id`,
  поэтому вариант: добавить в тред `source`-дискриминатор (миграция) ЛИБО отдельная тред-таблица для сообщений.
- (Реакции у сообщений уже есть — переиспользуем.)

### Фаза 5 — Чистка
- Убрать подвкладку «Чат» и связанные бейджи; выверить непрочитанные.
